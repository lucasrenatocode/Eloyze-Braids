# Landing Page — Trancista

Landing page desenvolvida para uma profissional especializada em tranças, com o objetivo de apresentar seus serviços, fortalecer sua presença digital e facilitar o contato com clientes.

## Funcionalidades

- Apresentação profissional da trancista.
- Exibição dos serviços oferecidos.
- Botões de agendamento com redirecionamento direto para o WhatsApp.
- Layout responsivo para dispositivos móveis, tablets e desktops.
- Interface intuitiva e navegação simplificada.

## Tecnologias utilizadas

- React
- TypeScript
- Tailwind CSS
- Vite

## Design

O projeto foi desenvolvido com foco em uma identidade visual elegante e moderna, valorizando a apresentação dos serviços e proporcionando uma experiência agradável aos visitantes.

## Objetivo

Criar uma presença digital profissional para a trancista, facilitando a divulgação do seu trabalho e tornando o processo de agendamento mais acessível.
